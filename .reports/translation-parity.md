Every string the port shows a user is marked and marked with upstream's exact
bytes — including the mnemonic underscores (`_New Time Control`), the
no-full-stop summary (`Time games of over-the-board chess`), the literal

so every msgid they contribute survives unchanged.

Three rows do not reconcile.

### T1 — the `a11y`-context timer labels never reach a user

Upstream sets each clock face's accessible label twice, from two different
msgids:

| Where | msgctxt | msgid |
|---|---|---|
| `src/gtk/window.ui:214` (initial, on `a_timer`) | `a11y` | `Player white timer` |
| `src/gtk/window.ui:225` (initial, on `b_timer`) | `a11y` | `Player black timer` |
| `src/timerbutton.py:58` (`on_white`) | — | `Player white timer` |
| `src/timerbutton.py:63` (`on_black`) | — | `Player black timer` |

The port has only the second pair, in
`lib/chess_clock/timer_button.rb:38-39`. The census confirms it: for
`a11y | Player white timer` upstream has a `single` occurrence at
`src/gtk/window.ui:214` and the port has **42 `po` occurrences and no source
occurrence at all**. The same for `Player black timer`.

So two msgids — translated in all 42 languages, 84 translated strings — are
dead in this port. A screen-reader user does still hear a translated label,
because the no-context pair is the one the port sets, which is why this is a
dead-msgid gap rather than an untranslated-UI gap. It is still a gap: 84
translations that reach a user upstream reach nobody here.

### T2 — the eight `shortcut window` titles are invisible to every extractor

`lib/chess_clock/shortcuts_window.rb:36-42`:

```ruby
def self.title(msgid)
  p_(CONTEXT, msgid).gsub("&", "&amp;")…
end
```

and then `#{title("Game")}` inside the heredoc. At runtime this is correct —
`p_("shortcut window", "Game")` is exactly upstream's lookup key, and all eight
titles are translated. But the marker's arguments are never literals at the
call site, so `xgettext`, `rxgettext` and the census all see one unresolved
row:

```
!unresolved	p_(CONTEXT, msgid)         .gsub("&", "&amp;")         .gsub("<
```

and zero source occurrences for any of the eight `shortcut window` msgids. The
moment anyone regenerates the `.pot` from `po/POTFILES.in` (the task **G10**
says is still owed), all eight entries are dropped from it, and the next
`msgmerge` marks 336 translations obsolete across 42 languages.

### T3 — two port-only msgids with no catalogue entry

`lib/chess_clock/about_dialog.rb:57-58` marks `Translate` and `Contribute` for
translation. `AdwAboutDialog` has no property for `<url type="translate">` or
`<url type="contribute">`, so the port adds them through `add_link`, which
needs a visible title. Upstream never needed one, so neither string exists in
any of the 42 catalogues: both are English in every locale.
